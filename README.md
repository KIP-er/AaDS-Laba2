# Лабораторная работа №2. Списки

Шаблонный класс `LinkedList<T>` на C++23.

## Возможности

- Двусвязный циклический список.
- Конструкторы по умолчанию, копирования и случайного заполнения.
- Копирование и присваивание списков.
- Добавление и удаление элементов в начале и конце списка.
- Добавление другого списка в начало или конец.
- Удаление всех элементов с заданным значением.
- Доступ к элементам по индексу.
- Вывод списка на экран.
- Разворот списка в обратном порядке.
- Консольное меню для проверки работы списка.

## Решаемая задача

Развернуть двусвязный циклический список в обратном направлении.

## Требования

- CMake 4.1+.
- Компилятор с поддержкой C++23 и `import std;`.
